# アプリ名: Hayate

2026-11-10 に決めた。画面・ストアに出る名前は **Hayate** (疾風・はやて)。

## 条件

- Apple Watch 専用に見えない名前 (iPhone の Siri やショートカットからも使える)
- webhook のような専門用語を入れない (技術的な説明はストアのサブタイトルに回す)
- 海外でもそのまま読める。日本語なら発音しやすい音だけ (ず・つ などは避ける)
- 「言った瞬間に飛んでいく」速さが出る

## 決めたこと

- 内部の名前 (ターゲット・`WatchHookCore`・Bundle ID `com.nabettu.watchhook`・ウィジェットの kind・`X-WatchHook-Message-Id`・`User-Agent: WatchHook/1`) は変えない。
  Bundle ID はストアに出した後は変えられず、ヘッダ名は受け手の実装が依存するため
- Siri には日本語で「はやてで飛ばして」(または「はやてで記録」) と話すので、`INAlternativeAppNames` に「はやて」を入れた (iOS・watchOS のアプリ)。英語の Siri 向けに `Voice Hook` / `Wrist Note` も入れた (未確認)

## リポジトリ名 (2026-11-13)

公開に合わせて GitHub のリポジトリを `nabettu/watchhook` から **`nabettu/hayate`** に変えた (旧 URL は GitHub が転送する)。
コード・Xcode のターゲット・Core パッケージ・Bundle ID・`X-WatchHook-*` ヘッダ・`User-Agent: WatchHook/1` は **WatchHook のまま** (ユーザー決定)。
Bundle ID は App Store Connect に登録済みで変えられず、ヘッダは受け口の仕様なので、名前を揃えるためだけに変えない。

## Siri の言い方 (2026-11-15。実機の Apple Watch・日本語の Siri)

| 言い方 | 結果 |
|---|---|
| はやてで送って | 「誰に送信しますか？」(標準のメッセージ送信)。ショートカットをオンにした後でも「Hayate とメッセージのどちら？」と聞き返すか、「誰に？」になる |
| はやてでメモ (して) | 「メモの作成に対応していません」(標準のメモ作成に回る。アプリ名は聞き取れている) |
| はやてで記録 | 初回に「ショートカットをオンにしますか？」→ オンにすると「何をメモしますか？」→ 送れた |
| はやてで飛ばして | 「何をメモしますか？」→ 送れた。紙飛行機の演出に合うので、使い方・ストア・スクショではこちらを前に出す (ユーザー決定)。フレーズが入る前のビルドでは「はやてを開く」と取られてアプリが開いた |

- 「はやて」は日本語で人の名前として扱われやすく、「〜に送って」「〜で送って」は宛先付きのメッセージ送信に取られる。Siri の標準機能 (メッセージ・メモ) は App Shortcuts のフレーズより先に判定されるので、**「送る」「メモ」を避けた動詞にする**
- 初回の「ショートカットをオンにしますか？」で断ると、watchOS には戻す設定が無いという報告がある (未確認)。使い方に書くなら「オンにする」を選ぶよう添える
- ショートカット App で自分で名前を付けたショートカットは、アプリ名なしの好きな言い方で呼べる (確実な逃げ道)
- ほかの 44 言語のフレーズは「Send with Hayate」の訳のまま。実機では試していない
